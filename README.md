# Local LLM Starter 🚀

A beginner-friendly project for exploring locally hosted AI using Ollama and Open WebUI.

## About

This project documents my experiments with running large language models locally rather than relying entirely on cloud-based AI services.

The goal is to make local AI experimentation easier for students and developers by documenting setup, basic usage, troubleshooting, and future experiments.

## Technologies

- Ollama
- Open WebUI
- Docker
- Local open-source LLMs

## What I'm exploring

- Running LLMs locally
- Prompt experimentation
- Local AI workflows
- Privacy-conscious AI usage
- AI-assisted programming and automation
- Future experiments with RAG and document processing
